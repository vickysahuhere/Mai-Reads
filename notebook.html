About Study Notebooks: Offline Multi-Document Binders for Research & Study

Mai-Reads Study Notebooks provide a distraction-free environment for organizing and reading multiple PDF and DOCX documents simultaneously. Whether studying for college exams, reading scientific papers, or comparing business reports, Study Notebooks allow you to create unified document collections with zero cloud uploads.

Key Features of Study Notebooks

  • Multi-Document Bundling: Group multiple PDF and Microsoft Word files into structured binders.
  • Instant Tab Navigation: 1-click document switching with full scroll position and highlight retention.
  • Unified Study Notes Scratchpad: Jot notes directly alongside your documents with auto-saving to local IndexedDB.
  • 100% Privacy & Offline PWA: No accounts required, no telemetry, and zero document uploads.

Install Mai-Reads App

Install Mai-Reads directly to your device for an offline, standalone desktop experience with zero browser window distractions.

1-Click Installation Ready

Click below to install Mai-Reads directly to your system.

Chrome / Edge (Desktop)

Click the Install icon in the address bar, or click Menu → Cast, save and share → Install Mai-Reads.

iOS (iPhone & iPad)

Tap the Share icon in Safari, scroll down, and tap Add to Home Screen.

macOS (Safari)

In the top menu bar, click File → Add to Dock…
